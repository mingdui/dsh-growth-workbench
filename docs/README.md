## 四篇

| 文档 | 回答什么问题 |
|---|---|
| [产品文档](产品文档.md) | 给谁做的、怎么用、有哪些规则 |
| [架构文档](架构文档.md) | 怎么实现的、和 DSH 怎么接、数据长什么样、怎么验证 |
| [产品蓝图](产品蓝图.md) | 现在有什么、接下来做什么、**明确不做什么** |
| [二次开发](二次开发.md) | 从哪读代码、常见的五种改法、不能破的边界、怎么改成自己的 |

## 先看哪一篇

- **想用**：README → [产品文档](产品文档.md)（用户旅程那一节）
- **想改代码**：[二次开发](二次开发.md) → [架构文档](架构文档.md)（与 DSH 的接缝、扩展点）
- **想判断值不值得投入**：[产品蓝图](产品蓝图.md)（现在有什么、明确不做什么）

## 四篇之间

```
产品蓝图     接下来做什么，明确不做什么
    │
    ▼
产品文档     规则是什么                          ← 规则真相源，可以独立读懂
    │
    ▼
架构文档     规则怎么变成不会静默出错的代码
    │
    ▼
二次开发     怎么在这套规则上做你自己的版本
```

**冲突时以产品文档为准。** 架构文档与二次开发只写"代码怎么保证"，不复述规则本身。
