# 产品蓝图

这份文档只说三件事：**现在有什么**、**接下来做什么**、**明确不做什么**。

已经做出来的功能不在这里展开 —— 怎么用看[产品文档](产品文档.md)，怎么实现看[架构文档](架构文档.md)，什么时候改的看 [CHANGELOG](../CHANGELOG.md)。

## 一、现在有什么

| 维度 | 现状 |
|---|---|
| 方向目录 | 11 个方向，**每个都自带能力模型**，选中即可逐项自评；模型状态都是 `draft`（随版本发布，未经行业校准，页面如实标注） |
| 路线 | 3 条（稳妥 / 冲刺 / 系统） |
| 计划 | 两段式：**第一段必须排到天**（写入门禁强制），后续阶段只排到周 |
| 任务 | 8 字段合同；预计 15-60 分钟；标识一经分配永不复用；每道题可带**学习资料**（怎么上手 / AI 汇总 / 来源） |
| 执行 | 「今日」一次只给一件事；右侧窄栏同一份数据；证据支持文字、图片、文件（csv / json / txt / md / zip / pdf）与三档（自述 / 过程 / 成果） |
| 节奏 | 进度可以**提前于日历**（「继续做下一天」），也可以退回（「回到日历节奏」）；打卡日期始终记真实日期 |
| 考核 | 两档：节点小考（每周，定向）与阶段大考（阶段走完，全量）；四维各 0-25、四档定级、8 行反馈表、调整版任务 |
| 看图 | 四维趋势折线；每周完成率柱（那一周没排到天就不画柱，不是 0%） |
| 数据 | `$DSH_HOME/growth-workbench/` 下四份 JSON + `evidence/` + `workspace/`；一次导出；无账号、无云 |
| 接法 | 左侧整页（四个页签）+ 右侧「今日」窄栏；Agent 侧 7 个 `growth_*` 工具 |

## 二、接下来做什么

按「用户现在会撞上什么」排，不按技术好看排。

| 优先级 | 做什么 | 为什么是它 | 怎么算做完 |
|---|---|---|---|
| 1 | **能力曲线画出来** | 数据已经齐了（逐项曲线点带来源与置信度），但页面上没有图 —— 现在只能看到四维在动，看不到"哪一项在动" | 能力项折线；每个点可点开看它的证据档位与来源；**定向轮的点不连线**（用子集冒充全域会读出不存在的提升） |
| 2 | **考核提醒** | 下一场考核写在计划与报告里，没有定时器："该考了"只有打开页面才知道 | 到点提醒一次（宿主侧挂一个 `ctx.effect` 定时器，读计划里的下一场日期）；一天最多一次，不打扰 |
| 3 | **真模型的端到端验收** | 工具是拿固定输入验的；"AI 读完简报能不能打出合理分数"没有验过 | 一份真实对话的验收记录：用同一份数据跑几轮考核，记录 rubric 偏差与判据一致性 |
| 4 | **方向包 / 主题包** | 加一个方向现在要改源码（`model.mjs`）；换配色也要改代码 | 目录能挂外部 JSON（方向 + 能力模型 + 自查题，过同一道校验器）；主题（配色 / 字体）可替换 |
| 5 | **数据可导入** | 导出有了，导入没有 —— 换机器、搬沙箱只能手工 | `POST /gw/api/import`：带版本校验与冲突提示，不静默覆盖 |

## 三、明确不做什么

| 不做 | 理由 |
|---|---|
| **不替用户打分** | 打分是这套数字唯一的重量来源。AI 替你打，gap、补强优先级、曲线就一起失去意义 |
| **不为留存放松证据门槛** | 门槛松一次，之后每个分数都要打折。宁可显得冷，也不做一个打卡玩具 |
| **不因为断了一天就惩罚** | 连续打卡是**描述**，不是债。断一天只反映在读数上，不追加任何惩罚机制 |
| **不做云同步 / 账号体系** | 数据在本机是这个产品的信任基础：没有账号，就没有"你的成长数据在别人服务器上"这件事 |
| **不引运行时依赖** | 图表与徽章都是手写 SVG。依赖会带来构建步骤、授权与供应链问题，而这里要的是十年后还能 `git clone` 就跑 |
| **不承诺结果** | 它产出的是**可核对的证据链**，不是"学完就能拿到 offer"。任何把它包装成结果保证的话术都不写 |

## 四、风险与对策

| 风险 | 会怎样 | 对策 |
|---|---|---|
| 计划质量波动 | 同一份画像两次生成的计划差很多 | 结构恒定的部分不交给模型自由发挥：8 字段合同、天区间、标识分配、第一段必须排到天，全部由门禁强制 |
| 能力模型未经校准 | 由它推出来的分数看起来比实际权威 | 模型自己带 `status: draft`，页面在每个读数旁边如实标注；锚点由人复核后才升档 |
| 用户中途停下 | 计划还在，人走了 | 读数只描述事实（完成率、连续天数），不做催促；回来时"接下来要做"仍然指得出下一步 |
| 数据只有一份 | 误删或磁盘故障就是全丢 | 四份 JSON + `evidence/` 都在一个目录里，一次 `export` 全带走；写入全部原子化（临时文件 + `rename`） |
| 生成的内容不可信 | 编出来的链接、编出来的锚点 | 链接必须来自真实检索（查不到就如实说没有）；锚点不许占位；考核必须四维齐全，缺数据记 `未提交` 而不是 0 |
| 绑定 DSH | 宿主变了产品就得跟 | 领域层（模型 / 门禁 / 存储）不 import 任何宿主包，能在普通 `node` 里跑；换宿主只需重写传输、工具与界面三端 |
